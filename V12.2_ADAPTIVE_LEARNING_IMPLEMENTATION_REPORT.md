# DOOM V12.2 — Adaptive Learning: Implementation Report

**Date:** 2026-10-04 · **Branch:** DOOM-V10 · **Base:** `03fbbe5` (`V12.1-FREEZE`)

## 1. Architecture

```
user turn (explicit first-person statement) ─┐
V8.28 Goal Experiences (owner, bounded) ─────┤
                                              ▼
outcome analysis → pattern extraction → candidate → validation → learned-knowledge store
                                                                        │ (owner-scoped)
next cycle: AdaptiveLearning.retrieve() → caller context (learned_* keys) → Context Fusion
```

- **Builds on, does not replace:** V8.27 User Model, V8.28 Goal Experience, V11.4 Advanced Memory, Context Fusion.
- **Why a separate store:** the V8.27 User Model has no provenance for *inferred* knowledge (`USER_EXPLICIT`, `PROJECTED_MEMORY`, `USER_CONFIRMED` only) and is capped at 32 entries. Writing inferences into it would mislabel provenance or require changing frozen V8 types. Learned items therefore carry explicit `source` (`USER_EXPLICIT` / `EXPERIENCE_INFERENCE`), `confidence`, `evidence` and `explanation`.
- **Retrieval:** through the hardened V11.8 caller-context channel, which is lowest precedence, scalar-only, privacy-filtered and bounded. Caller-supplied keys, such as monitoring metadata, override learned keys.

## 2. Knowledge kinds

| Kind | Source | Promotion rule |
|---|---|---|
| FACT | explicit "my X is Y" (non-sensitive) | immediately (confidence 0.9) |
| PREFERENCE | explicit "I prefer A over B / A for D", "my favorite X is Y", "I (don't) like X" | immediately; conflicts → newest explicit wins, older SUPERSEDED |
| TEMPORARY_CONTEXT | "today / right now / this week I'm working on X" | session-scoped; expires (12 h / 7 d); never durable |
| WORKFLOW | recurring step signature across experiences | ≥3 occurrences and success rate ≥0.67 (reliable) or ≤0.34 (unreliable, with usual blocker) |
| GOAL_PATTERN | recurring goal tag or step signature | ≥2 occurrences |
| HABIT | dominant time-of-day of a recurring pattern | ≥3 occurrences and ≥70% in one bucket |
| LOW_CONFIDENCE_INFERENCE | any inference below threshold | never retrieved; visible in `explain()` |

Inferred confidence is `min(0.95, 0.4 + 0.15·(n−1)) × consistency`; promotion requires confidence ≥0.6 plus the minimum evidence. Staleness: explicit items after 180 days and inferred items after 30 days without reaffirmation become STALE and are not retrieved.

## 3. Safety properties

- **Owner-scoped:** foreign-owner records passed in are ignored, and other owners retrieve nothing.
- **Bounded:**
  - 64 items per owner (active first);
  - 8 evidence references per item;
  - 6 retrieved keys;
  - values ≤60 characters, keys ≤48;
  - statements >240 characters are ignored.
- **No arbitrary text:** only pattern-extracted values and structural experience signatures are stored. Evidence is a SHA-256 digest reference, never the utterance (verified on the persisted JSON).
- **Never sensitive:** a sensitive-attribute and secret filter (health, religion, politics, sexuality, ethnicity, immigration, criminal, finances, identifiers, contact/address/birthday/age, credentials), plus the V8.27 `is_sensitive_profile_content` policy.
- **Explainable:** `explain(owner)` lists classification, status, source, confidence, evidence count and explanation.
- **Reversible:** `forget(owner, key=None)`. Forgotten knowledge is never retrieved or re-inferred from the same evidence; only a fresh explicit restatement re-learns it.
- **Deterministic:** identical inputs and clock produce identical output.
- **Monitor input is not a user statement:** cycles with `monitoring_trigger` never learn statements.
- **Duplicate evidence:** the same experience appearing twice in the input counts once (defect found by test and fixed).
- **Failure isolation:** learning errors are recorded in `stages.adaptive_learning.error` and never fail a cycle.
- **Persistence:** in-memory by default. Setting `DOOM_LEARNING_STORE_PATH` enables local JSON persistence, written atomically (temp file + `os.replace`).

## 5. Limitations

- Statement extraction is deliberately narrow (explicit patterns, English only). Paraphrases are not learned, by design: the system under-learns rather than over-infers.
- Inferred patterns are derived from the experience store's most recent window (`list_experiences` returns ≤16).
- Learned knowledge reaches Context Fusion and reasoning. The V8 local responder's prompt uses V8 memory/user-model sources, not learned items.
