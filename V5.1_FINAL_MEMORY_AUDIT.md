## 1. Architecture

DOOM V5.1 introduces a durable, structured, retrievable, and privacy-governed memory subsystem built directly upon the hardened V4.2 cognitive core.

```
+---------------------------------------------------------------------------------------------------+
|                                       DOOM V4.2 / V5.1 COGNITIVE CORE                             |
|                                                                                                   |
|  DOOMCore.process_request()                                                                       |
|      |                                                                                            |
|      v                                                                                            |
|  CognitiveEngine.process()                                                                        |
|      |                                                                                            |
|      +---> [1. RETRIEVE] ---> MemoryRetriever.retrieve() ---> MemoryRanker ---> MemoryContext     |
|      |                                                                                            |
|      +---> [2. REASON/PLAN] -> CognitivePlan (injected with MemoryContext.context_summary)       |
|      |                                                                                            |
|      +---> [3. EXECUTE] -----> TaskEngine / ToolRegistry                                          |
|      |                                                                                            |
|      +---> [4. VERIFY] ------> GroundTruthVerifier                                                |
|      |                                                                                            |
|      +---> [5. RECORD] ------> write_experience() (ONLY if verified == True)                      |
|                                     |                                                             |
|                                     v                                                             |
|                               MemoryManager.store()                                               |
|                                     |                                                             |
|                                     v                                                             |
|                               MemoryWritePolicy.evaluate()                                        |
|                                     |                                                             |
|                                     v                                                             |
|                               MemoryValidator.validate()                                          |
|                                     |                                                             |
|                                     v                                                             |
|                               MemoryRepository.store()                                            |
|                                     |                                                             |
|                                     v                                                             |
|                          PostgreSQL: memory_records                                               |
+---------------------------------------------------------------------------------------------------+
```

- **Canonical Authority**: [MemoryManager](file:///c:/Users/dell/Desktop/DOOM/memory/manager.py#L64) (`memory/manager.py`) is the sole authoritative entry point for durable V5.1 memory creation, mutation, search, and retrieval.
- **Cognitive Integration**: Integrated in [CognitiveEngine.process()](file:///c:/Users/dell/Desktop/DOOM/core/cognition/engine.py#L82-L116) (`core/cognition/engine.py`) and [CognitiveBridge.execute_plan()](file:///c:/Users/dell/Desktop/DOOM/core/cognition/bridge.py#L603-L630) (`core/cognition/bridge.py`).
- **Isolation Principle**: Memory failures are completely isolated. Any database outage, indexing exception, or parsing failure degrades gracefully to an empty `MemoryContext` without interrupting cognition or task execution.

## 4. Retrieval & Ranking

- **Retrieval Engine**: [MemoryRetriever](file:///c:/Users/dell/Desktop/DOOM/memory/retrieval.py#L17) (`memory/retrieval.py`).
- **Scoring Pipeline**: [MemoryRanker](file:///c:/Users/dell/Desktop/DOOM/memory/ranking.py#L14) (`memory/ranking.py`).
  - Lexical token overlap (content matching).
  - Tag overlap match bonus.
  - Project ID alignment (+0.25 boost).
  - Recency weighting (exponential half-life decay).
  - Confidence weighting (HIGH: 1.0, MEDIUM: 0.7, LOW: 0.4).
  - Importance multiplier (`importance * 0.5`).
- **Relevance Gate**: Records with scores below `RELEVANCE_THRESHOLD` (0.35) are pruned.
- **Bounded Ingestion**: Bounded candidate search (`limit=50`), output clamped to `MAX_RETRIEVAL_RECORDS` (10).

## 5. Policy & Validation

- **Policy Gate**: [MemoryWritePolicy](file:///c:/Users/dell/Desktop/DOOM/memory/policy.py#L22) (`memory/policy.py`).
  - Evaluates memory worthiness, source authenticity, confidence constraints, and privacy classification.
  - Only `USER_EXPLICIT` commands receive `HIGH` confidence by default.
  - LLM-derived or conversational memories receive `MEDIUM` or `LOW` confidence and `UNVERIFIED` status.
- **Content Validator**: [MemoryValidator](file:///c:/Users/dell/Desktop/DOOM/memory/validators.py#L12) (`memory/validators.py`).
  - Minimum content length: 3 characters.
  - Maximum content length: 4000 characters.
  - Rejects chain-of-thought artifacts (`let me think`, `<thinking>`, `step 1:`).
  - Rejects credential and secret patterns (`password`, `api_key`, `token`, `sk-`, `ghp_`, long encoded hashes).

## 6. Privacy & Security

- **Privacy Classes**: `NORMAL`, `PRIVATE`, `SENSITIVE` ([memory/types.py](file:///c:/Users/dell/Desktop/DOOM/memory/types.py#L67)).
- **Sensitive Protection**: `SENSITIVE` memories are strictly excluded from automated general retrieval in `CognitiveEngine`.
- **Telemetry Sanitization**: `MemoryTelemetry` and `MemoryContext.to_dict()` deliberately omit raw content strings and private values, reporting only numerical metrics and timestamps.
- **WebSocket Safety**: Event broadcasts emit only metadata (`memory_id`, `memory_type`, `latency_ms`), never raw private memory text.

---

## 7. Verification Boundary

- **Principle**: Memory confidence must never substitute for empirical ground truth.
- **Verification Rule**: Task experience records (`MemoryType.EXPERIENCE`) are marked `VerificationStatus.VERIFIED` **only** when `GroundTruthVerifier` has validated the physical side effects on the filesystem or operating system.
- **Failure Defense**: Incomplete, errored, or partially failed tasks are flagged `UNVERIFIED` with `LOW` confidence, preventing hallucinated success loops.

## 8. Supersession & Lifecycle

- **State Model**: `ACTIVE`, `SUPERSEDED`, `ARCHIVED`, `DELETED`, `PENDING_VERIFICATION`.
- **Supersession Mechanism**: [MemoryLifecycle.supersede()](file:///c:/Users/dell/Desktop/DOOM/memory/lifecycle.py#L23) links `new_record.supersedes_memory_id = old_record.memory_id` and transitions the prior record to `MemoryStatus.SUPERSEDED`.
- **Soft Deletion**: [MemoryLifecycle.delete()](file:///c:/Users/dell/Desktop/DOOM/memory/lifecycle.py#L65) updates status to `DELETED`. No hard SQL `DELETE` cascades occur, preserving the historical audit trail.

## 13. Known Risks & Architectural Boundaries

1. **Exact-Token Lexical Matching vs. Future Vector Embeddings**: V5.1 deliberately uses bounded SQL ILIKE and token overlap rather than vector embeddings. Semantically distant synonyms without token overlap rely on legacy profile facts or task context. (V5.2 will introduce hybrid embeddings).
2. **PostgreSQL Local Prerequisite**: When PostgreSQL is offline, `MemoryRepository` gracefully degrades to empty results. No local SQLite fallback was mandated for V5.1.
3. **Regex Pattern Boundedness**: Regex secret detection catches standard high-entropy tokens and credentials; non-standard obfuscated passwords require strict adherence to system prompts.
