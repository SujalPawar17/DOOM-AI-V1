# DOOM V12.4 — Multimodal Context: Implementation Report

**Date:** 2026-10-04 · **Branch:** DOOM-V10 · **Base:** `1dda462` (`V12.3-FREEZE`)

## 1. Architecture

```
Text | Voice transcript | Image | Screenshot | Document | Structured data | System event
  -> PerceptionNormalizer (deterministic, local, no models)
  -> PerceptualItem {item_id, owner, session, modality, source, timestamp, summary,
                     content_digest, size, metadata, privacy, provenance}
  -> UnifiedPerceptualContext (per owner+session: ≤32 items, 1 h TTL, deduplicated)
  -> compose_caller_context(caller/monitoring > perceptual > learned, ≤16 keys)
  -> Context Fusion (caller_context provenance) -> V11/V12 cognitive pipeline
```

| Modality | Normalization | Privacy |
|---|---|---|
| TEXT | bounded, redacted summary | PUBLIC |
| VOICE | transcript from the **existing frozen STT** (passed in), language, confidence; no audio handled | PUBLIC |
| IMAGE | PNG/JPEG/GIF/WebP header parsing (format, dimensions); optional sanitized caption; pixels never decoded | PUBLIC |
| SCREENSHOT | header metadata only; never captioned; content withheld from context | **SENSITIVE** |
| DOCUMENT | text types: words, lines, bounded excerpt; PDF: page count only; binary: size only | PUBLIC |
| STRUCTURED_DATA | strict JSON; shape summary (keys / length) | PUBLIC |
| SYSTEM_EVENT | type and bounded attributes | PUBLIC |

- **Deterministic IDs:** `sha256(owner|session|modality|source|content_sha256)[:24]`. Timestamps are excluded, so identical content in the same owner and session deduplicates, while different owners or sessions never collide.
- **Bounds:** 5 MB payload, 240-character summaries, 12 metadata entries, 32 items per session, 1 h TTL, 3 recent percepts plus a count exposed to cognition.
- **Context budget:** a priority merge guarantees that caller and monitoring keys are never crowded out of the 16-key caller-context budget by perceptual or learned keys (tested with a full budget).

## 2. Integration

`V12CognitiveOrchestrator` gains:
- `perception` (UnifiedPerceptualContext);
- `normalizer` (PerceptionNormalizer);
- `perceive(item)`;
- a `perception` stage in each cycle's result.

The V11 pipeline itself is unchanged.

## 3. Files

- New: `core/v12/multimodal.py`, `test_v12_4_multimodal_context.py` (16 tests).
- Modified: `core/v12/cognitive_orchestrator.py`.

## 4. Defects found by tests and fixed

- Structured data was silently stringified via `default=str`, violating the strict-JSON contract. It is now strict.

## 5. Limitations

- **No semantic image or screenshot understanding:** there is no vision or OCR model, and adding one is outside HARD $0 local scope unless a local model is explicitly authorized.
- **PDF text is not extracted:** pages are counted only.
- **Voice relies entirely on the existing frozen STT output:** no live microphone path was added.
