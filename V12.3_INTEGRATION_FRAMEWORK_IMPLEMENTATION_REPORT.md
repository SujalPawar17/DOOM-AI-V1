# DOOM V12.3 — External Integration Framework: Implementation Report

**Date:** 2026-10-04 · **Branch:** DOOM-V10 · **Base:** `4985c6f` (`V12.2-FREEZE`)

## 1. Architecture

```
Intent -> ToolSelector (deterministic proposal only)
       -> ConnectorRequest (owner, session, connector, action, args)
       -> IntegrationGateway.invoke(request, trusted IntegrationIdentity, authorized_request_hash?)
            1 identity  2 owner/session  3 registry  4 enabled  5 argument validation
            6 Cost Guard (existing attestations)  7 authorization (claimed, single-use, TTL)
            8 bounded execution (4-worker pool, timeout, retries only if idempotent & non-mutating)
            9 verification (connector-declared)  10 outcome + V8.28 experience (executed attempts only)
       -> ConnectorResult (status, redacted bounded output, verified, attempts, pending_id)
```

**Connector declaration (`ConnectorSpec`):** capability, actions (`ActionSpec`: params, risk, mutates, idempotent, verification), cost resource, permissions, owner scope (OWNER_ONLY, enforced by the registry), session requirement, timeout and retry policy (capped at 2 by the registry).

## 2. Initial connectors (local, safe, testable)

| Connector | Actions | Risk | Safety |
|---|---|---|---|
| `filesystem` | `list_dir`, `read_text`, `write_text` | LOW / LOW / **MEDIUM (approval)** | Per-owner sandbox root. Absolute, `..`, symlink and cross-drive escapes refused. Sensitive names (`.env`, keys, credentials…) hidden and refused. Atomic writes verified by re-read SHA-256. Bounded reads (64 KB) and listings (200). |
| `git` | `status`, `current_branch`, `log(limit≤20)` | LOW | Read-only. Fixed argv, `shell=False`, 4 s timeout, no prompts, no optional locks. |
| `sqlite` | `query(sql, limit≤200)` | LOW | `mode=ro` URI plus `PRAGMA query_only`. Single SELECT/WITH only; write and admin keywords refused. |
| `github_api` | `list_issues` | LOW | Cloud declaration. **Disabled by default**, and its resource (CONNECTOR/github) is unattested, so the Cost Guard blocks it even when enabled. |

All local connectors use the existing `OTHER/local_filesystem` LOCAL_FREE attestation. **No Cost Guard entries were added.**

## 3. Security decisions

- **Approval must be claimed:** the authorized hash is the deterministic request hash, so knowing it is *not* authorization.
  - The gateway redeems only a `CLAIMED` approval for the same owner, session and request hash, then marks it `USED` (single use, TTL 120 s, store bounded at 256).
  - A forged hash, tampered arguments, the wrong session and replay are all refused (tested).
  - This weakness was found in self-review before testing. The V8/V11 `authorized_plan_hash` has the same shape (it equals the plan hash) and is recorded for the Phase 11 audit.
- **Trusted identity:** owner and session come from `IntegrationIdentity` (trusted caller), never from the request.
- **Argument validation:** declared parameters only, typed (bool is not int), length- and range-bounded, NUL bytes refused, forbidden keys (shell, command, exec, credentials…) refused.
- **Outputs:** passed through V8 secret redaction, bounded (4,000 characters per string, 500 list items).
- **Experiences:** recorded only for attempts that actually executed (SUCCESS, CONNECTOR_FAILED, TIMEOUT, VERIFICATION_FAILED). Refusals and pending approvals never create records.

## 5. Limitations

- The tool selector is deterministic keyword rules for the initial connectors. It proposes requests; wiring proposals into the cognitive pipeline belongs to the unified-OS phase.
- A timed-out connector call cannot be forcibly killed (Python threads). The worker pool is bounded at 4, and connectors bound their own work (git 4 s subprocess timeout, sqlite busy timeout).
- No cloud connectors are implemented (HARD $0).
