The 3 V10.2 user-model failures are a **test-harness/environment gap**, not a code defect. The V8.27 user model is flag-gated by `PROACTIVE_V827_USER_MODEL_ENABLED`. `test_v10_8` sets this flag at import but `test_v10_2` does not, and the local `.env` does not define it.

With `PROACTIVE_V827_USER_MODEL_ENABLED=1`, **V10.2 = 10/10**. The pre-existing classification stands (same failures before V11.8); root cause is now identified.

The working-tree modification of `test_v10_2_memory_user_model_integration.py` (2026-10-03) is the V11.4 adaptation of its memory assertions to `advanced_memory_*` keys. Without it, the 3 memory tests fail against V11.4 Context Fusion. It is therefore part of the V11 lineage and is included.
