## 1. Scope

This is a complete audit of V11.1–V11.9 and the final regression matrix. V11.10 adds no features. It made three narrow, evidence-backed changes:

1. **V11.5 monitor never worked: fixed.** `_determine_event_priority` dereferenced `previous_state=None` on the first poll. The exception happened before `last_known_states` was recorded, so **every poll failed forever** (reproduced: 3/3 consecutive polls raised; `last_known_states` stayed empty). The `monitoring_errors` containment and V11.5's unit tests, which call helpers with a non-None previous state, masked it.
   - Fix: guard `previous_state` in that one branch; all other dereferences were already guarded.
   - Verified: the new regression tests fail on the pre-fix module (`sys.modules` injection) and pass on the fix. Real polls now run with 0 errors.
2. **V10.2 test harness: fixed.** The V8.27 user model is flag-gated (`PROACTIVE_V827_USER_MODEL_ENABLED`). `test_v10_2` never set it and depended on the local `.env`. It now uses `os.environ.setdefault(...)`, as `test_v10_8` does. V10.2 is now 10/10 (it was 7/10, classified pre-existing).
3. **`test_v11_10_final_audit.py` (7 tests):**
   - the monitor first-poll regression (2 tests);
   - HARD $0 decisions (local allowed; openai, gemini, elevenlabs, edge_tts, a non-loopback ollama host, world_act and browser blocked);
   - browser default OFF;
   - no forbidden imports (network, paid, browser, UI-automation, subprocess, audio) in V11 modules;
   - V11 never constructs VoiceEngine or audio outputs;
   - the V8 audit helper never raises.

AGENTS.md was updated with durable V11 facts (lineage, invariants, entry-point status, flag conventions).

## 5. Security / privacy / cost / authorization / plan integrity / isolation

- **HARD $0:** the Cost Guard is unchanged and decisions are asserted by test. There are no new dependencies, and no network, paid or cloud paths in V11 (static audit).
- **Authorization:** approval required stops execution. Stash and claim are single-use and session-scoped. Pending reuse is validated by V8 `pending_display`.
- **Plan integrity:** the V8 executor re-hashes plans; a tampered plan returns `PLAN_HASH_MISMATCH` (V11.8 E).
- **Verification:** derived only from executor facts; no fabricated success, execution IDs or experiences (V11.8 A/B/D/F).
- **Owner/session isolation:** the crafted cache-key collision was fixed (V11.9); two-owner long sessions and cross-owner experience isolation are tested.
- **Privacy:**
  - Context Fusion no longer dumps memory or user-model contents to stdout.
  - Caller context is privacy-filtered.
  - The V8.28 store and redaction are unchanged.
- **Browser automation:** OFF by default (asserted). Browser steps are Cost-Guard-blocked in V11.
- **V9 / STT:** no diff. V11 constructs no VoiceEngine or audio outputs (asserted).
