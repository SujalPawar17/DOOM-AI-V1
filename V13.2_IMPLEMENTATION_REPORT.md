## 2. What V13.2 really provides (`core/v13/multimodal_understanding.py`)

| Capability | Implementation | Truth label |
|---|---|---|
| Image metadata | Pillow safe decode (verify + load), 10 MB / 40 MP limits, decompression-bomb refusal | real |
| Visual description | **Measured low-level analysis:** orientation, brightness, contrast, saturation, dominant colour names, edge density (OpenCV Canny). Text always starts with "low-level analysis:" | real, explicitly *not* semantic |
| Semantic description / visual Q&A | `LocalOllamaVisionProvider` uses an installed Ollama model only if it declares the `vision` capability. Loopback only, Cost Guard LLM check first, redacted bounded answers | boundary: **`VISION_MODEL_UNAVAILABLE` in this environment** (verified live) |
| Content in images | QR-code decoding (OpenCV), secret-redacted, ≤200 characters | real |
| Unsupported / corrupt images | `UNSUPPORTED` (unknown format) vs `CORRUPT` (known signature, undecodable) vs `TOO_LARGE` | real |
| Documents | text types; **DOCX** (WordprocessingML via zip+XML); **PDF** (uncompressed and Flate content streams, `Tj`/`TJ` literals with escape handling) | real; PDFs with custom/CID font encodings → partial/unsupported |
| Unsupported documents | encrypted PDF, scanned/image-only PDF ("no OCR"), unknown formats → `UNSUPPORTED`; broken DOCX → `CORRUPT` | real |
| Privacy | V8 secret redaction on extracted text, QR payloads and model answers. Screenshots are never analysed semantically (V12.4 boundary kept) | real |
| Pipeline | `image_percept` / `document_percept` → V12.4 perceptual items (bounded, owner/session-scoped) → Context Fusion | real |

**V12.4 change:** `PerceptionNormalizer.document(..., extracted_text=None)` is an additive optional parameter (V12.4 16/16 re-run).

**Defect found by tests and fixed:** truncated images with a valid signature were reported UNSUPPORTED; they are now CORRUPT.

**Hardening (V13.6 security review):** `LocalOllamaVisionProvider.ask()` used to rely on its caller having checked `available()`. It now refuses on its own unless the endpoint is loopback **and** a vision-capable model was detected. It raises before any HTTP request. A regression assertion was added to `test_real_environment_reports_capability_truthfully`, which patches `requests.post` and verifies it is never called.

## 4. Limitations (honest)

- **No semantic image understanding or image Q&A on this machine.** It requires a locally installed vision-capable model (for example an Ollama `llava`-class model) installed by you. The code uses one automatically when present; nothing is faked.
- No OCR of text inside images or scanned PDFs.
- Complex PDFs (CID fonts, object streams) may extract partially or not at all.
